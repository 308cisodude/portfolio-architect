# Portfolio Architect Gateway — Comdirect v1.26.1

Version 1.26.1 keeps the established Comdirect App behavior unchanged while aligning package versions with the Portfolio Architect ISIN-first identity hotfix. No provider acquisition, OAuth/session, account-selection, authorized-cash or REST contract behavior changes in this App.

The App uses its own `/data/gateway` private volume and must be upgraded in place to retain private state.
