# Portfolio Architect v1.65.3 upgrade and acceptance

Update the integration and all four version-aligned Gateway Apps. Confirm `integration_version` and `engine_version` are `1.65.3`; check the four Gateway App versions. Reload the integration if needed; restart Home Assistant only if the update has not loaded. Replace the installed PA dashboard YAML with the matching generated English, German, or combined artifact if you manage that dashboard manually. A version update by itself cannot replace a manually copied dashboard.

In the investment plan, a stale DKB or Trade Republic statement should identify the relevant source in **Why the plan is not ready**. Refresh the authoritative statement and evaluate again; the blocker card should disappear once source evidence is current. A current `no_eligible_purchase` shows a separate policy/route explanation. These displays describe the current evidence and do not authorize an order.

For an unverified savings-plan route, **Policy findings with observed and expected evidence** should show its fund and `Savings plan route required` (or the German equivalent), `unavailable` observed and `available` expected, plus guidance to check the provider and update dated route evidence. A verified route should remove that error on evaluation. Remaining errors for other routes do not necessarily prevent a different eligible purchase.

The DKB FinTS research shadows remain App-private and independent of the plan. The booked-balance shadow becomes old after 24 hours unless manually refreshed; this should not by itself change planner cash or the authoritative DKB CSV state. Do not include private balances or account details in a public PR or issue.
