# Portfolio Architect v1.66.1

The five-minute DKB holdings comparison now names the source selected in the Gateway as authoritative. With FinTS selected, CSV is an inactive observation; with CSV selected, FinTS is a staged observation. The comparison remains read-only and does not choose a source or judge differences between values observed at different times.

The English and German reference dashboards show the observation date and freshness limit for sources that block a plan. When no purchase is eligible, the plan card summarizes up to three error-level policy findings with observed and expected evidence. The cash blocker explains that a zero authorization cap contributes no investment cash even if a bank balance is positive. Existing detailed findings remain available below the plan.

Acquisition, authority, no-fallback behavior, the DKB 14-day evidence limit, cash authorization and planner calculations are unchanged. No new credentials, bank reads, diagnostics or retained responses are introduced. The previously accepted DKB operating-account cap of EUR 0 stays a user setting, not a new default.
