# Generic CSV example

Use these mapping values in the native source flow:

```text
Encoding:              UTF-8
Delimiter:             Comma
Header row:            1
Number format:         Dot decimal
Instrument identifier: Identifier
Instrument name:       Security
Market value in EUR:   Market Value
ISIN column:           ISIN
Instrument type:       Asset Type
Currency column:       Currency
```

The identifiers and values are synthetic. The ISINs are format-valid examples
used only to demonstrate mapping.
